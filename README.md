1. Clone the repo from this link using the VS Code editor: `https://github.com/AmaduKamara/LENOSOL-TRAVELS-WEBDESIG-FINAL-PROJECT-DIT1101.git`
2. Open the cloned project with this command: `cd WEB_DESIGN_FINAL_PROJECT_LENOSOL_FOODS_BIT1102`
